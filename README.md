# Multibat Quick Power

Você é um especialista em Landing Pages de alta conversão para e-commerce e serviços. 

Crie uma Landing Page profissional e focada em geração de leads e vendas para a empresa Multibat 

(venda e instalação de baterias automotivas com entrega rápida).

CONTEXTO DA EMPRESA:

- Nome: Multibat Baterias

- Segmento: Venda e Instalação de Baterias Automotivas

- Localização: Vilhena/RO

- Público-alvo: Motoristas que precisam de bateria com urgência

- Oferta Principal: Bateria nova com entrega e instalação grátis em até 50 minutos

- Objetivo da LP: Gerar leads via WhatsApp e vendas diretas

- Marcas oferecidas: Moura, Heliar, Pioneiro, Maxfor

- Atendimento: 24h via WhatsApp

- Diferencial: Entrega rápida + instalação profissional + garantia de fábrica

IDENTIDADE VISUAL:

- Cor Primária: Azul Escuro (confiança, profissionalismo)

- Cor Secundária: Laranja/Verde (destaque, urgência, CTA)

- Tipografia Headlines: Bold, impactante, direto

- Tipografia Body: Clara, legível

- Estilo Visual: Moderno, confiável, comercial

- Elementos: Ícones de rapidez, segurança, profissionalismo

ESPECIFICAÇÕES TÉCNICAS:

1. Responsividade:

   - Mobile-first design

   - Breakpoints: 320px (mobile), 768px (tablet), 1024px (desktop)

   - Sticky CTA button no mobile (flutuante no rodapé com WhatsApp)

2. Performance:

   - Todas as imagens em formato WebP

   - Tamanho máximo: Hero (300KB), Cards (150KB cada)

   - Lazy loading para imagens abaixo da dobra

   - Otimizar para Core Web Vitals

3. Tracking:

   - Instalar Pixel da Meta no <head>

   - Instalar GA4 tag no <head>

   - Rastrear cliques em CTAs

   - Rastrear submissões de formulário/WhatsApp

4. SEO:

   - Meta Title: "Multibat | Bateria com Entrega e Instalação em até 50 Minutos"

   - Meta Description: "Baterias Moura, Heliar e Pioneiro com entrega e instalação grátis. Atendimento 24h via WhatsApp. Melhor preço garantido."

   - H1: "Bateria Nova com Entrega e Instalação Grátis em até 50 Minutos."

   - Headings estruturados (H2, H3)

   - Alt text em todas as imagens

5. Acessibilidade:

   - Contraste de cores WCAG AA

   - Labels em todos os campos

   - Navegação por teclado funcional

   - ARIA labels onde necessário

ANIMAÇÕES (Sugestões):

- Fade-in ao scroll para cada seção

- Hover suave nos cards (0.3s transition)

- Pulse suave no botão CTA principal

- Transição suave entre seções

- Contador de urgência (opcional): "Técnicos de plantão agora"

PRIORIDADES:

1. Garantir que o CTA WhatsApp funcione perfeitamente e esteja sempre visível

2. Otimizar para mobile (mais de 80% do tráfego virá de smartphones)

3. Manter a urgência e confiança ao longo da página

4. Focar em quebra de objeções (preço, garantia, atendimento)
